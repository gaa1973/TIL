TOEIC Part 5のコツ
	• 時制の一致 → 文中の過去形に合わせる
	• 前置詞の使い分け → 「by」は期限、「at」は時刻、「on」は日付、「in」は期間
	• 比較表現 → 「more/less + 形容詞 + than」が基本形

3️⃣ 形容詞 / 副詞の使い分け
	• 形容詞 (adjective) → 名詞を修飾する
		○ A correct answer（正しい答え）
		○ The new manager（新しいマネージャー）
	• 副詞 (adverb) → 動詞・形容詞・副詞を修飾する
		○ He answered correctly.（正しく答えた）
		○ The report was quickly finished.
👉 TOEICでは「be動詞 + 形容詞」が自然。
	• 例：The documents are correct.（正しい）
	• 誤り：The documents are correctly.（副詞なので不自然）
🎯 まとめ
	• 動詞の形 → 時制と構文に注意（require 人 to do, be + 過去分詞）
	• 比較級 → more/less + 形容詞 + than が基本
	• 形容詞/副詞 → 名詞を修飾するのは形容詞、動詞を修飾するのは副詞

1️⃣ 形容詞の語尾パターン
形容詞は 名詞を修飾 します。語尾に特徴があるものが多いです。
	• -ful → beautiful, helpful, useful
	• -ous → famous, dangerous, various
	• -ive → active, effective, expensive
	• -al → personal, cultural, natural
	• -able / -ible → comfortable, possible, reliable
	• -y → busy, happy, easy
👉 例：a beautiful garden（美しい庭）
2️⃣ 副詞の語尾パターン
副詞は 動詞・形容詞・副詞を修飾 します。
	• -ly が圧倒的に多い
		○ quickly, carefully, correctly, easily
	• 例外的に形容詞と同じ形の副詞もある
		○ fast（速い／速く）, hard（難しい／一生懸命に）, late（遅い／遅く）
👉 例：He answered quickly.（彼はすぐに答えた）
3️⃣ TOEICでの注意点
	• be動詞 + 形容詞 が自然
		○ The answer is correct.（答えは正しい）
	• 動詞 + 副詞 が自然
		○ He answered correctly.（彼は正しく答えた）
	• 「-ly」がついているからといって必ず副詞とは限らない
		○ friendly（形容詞）, lovely（形容詞）
🎯 まとめ
	• 形容詞の語尾 → -ful, -ous, -ive, -al, -able/-ible, -y など
	• 副詞の語尾 → 基本は -ly（ただし例外あり）
	• 使い分けのコツ → 名詞を修飾するなら形容詞、動詞を修飾するなら副詞


ポイント整理
	• require 人 to do → 動詞は原形
	• be動詞 + 過去分詞 → 修飾するのは副詞（-ly）
	• 「careful（形容詞）」は名詞を修飾、「carefully（副詞）」は動詞や文全体を修飾
	🧩 構造
		• require = ～を要求する、必要とする
		• 人 = 誰か（対象者）
		• to do = ～すること
	👉 全体で「人に～することを要求する」「人が～する必要がある」という意味になります。


1️⃣ be動詞の後 → 形容詞
	• be動詞 + 形容詞 が自然
	• 例：The answer is correct.（答えは正しい）
	• ❌ The answer is correctly（副詞なので不自然）
👉 「be動詞の後は名詞や形容詞が来る」と覚えると分かりやすいです。
2️⃣ 動詞を修飾 → 副詞
	• 動詞の動作を説明するときは副詞
	• 例：He answered correctly.（彼は正しく答えた）
	• ❌ He answered correct（形容詞なので不自然）
👉 「動詞の後にどうやって？どのように？と説明するなら副詞」。
3️⃣ 名詞を修飾 → 形容詞
	• 名詞の前に置いて説明するのは形容詞
	• 例：a beautiful garden（美しい庭）
	• ❌ a beautifully garden（副詞なので不自然）
4️⃣ 文全体や形容詞を修飾 → 副詞
	• 副詞は形容詞や副詞も修飾できる
	• 例：The movie was extremely interesting.（とても面白かった）
	• ここでは「interesting（形容詞）」を修飾しているので副詞。
5️⃣ TOEICでの見分け方まとめ
	• be動詞の後 → 形容詞
	• 動詞の後 → 副詞
	• 名詞の前 → 形容詞
	• 形容詞や副詞を強める → 副詞

🎯 まとめ
	• be動詞の後 → 形容詞
	• 動詞を修飾 → 副詞
	• 名詞を修飾 → 形容詞
	• 形容詞を強める → 副詞



まとめ
	• be動詞 + 形容詞 → 状態を表す（The report is clear.）
	• be動詞 + 過去分詞 → 受動態（The report was written.）
		○ この場合は「過去分詞」が動詞の一部なので、副詞で修飾する。
		○ The report was clearly written.


1⃣be動詞 + 形容詞（状態文）
	• 主語の「性質・状態」を説明する。
	• 例：The instructions were simple.（指示は簡単だった → 状態）
	• → この場合は 形容詞 が自然。
2️⃣ be動詞 + 過去分詞（受動態）
	• 主語が「～された」という動作の結果を表す。
	• 例：The presentation was prepared.（プレゼンは準備された → 受動態）
	• → この「prepared」は動詞の一部なので、修飾するのは 副詞。
	• 例：The presentation was carefully prepared.（注意深く準備された）


• look, seem, appear, feel, sound, taste, smell なども「主語と性質をつなぐ」働きをするので linking verb（連結動詞） と呼ばれます。
	○ The design looks elegant.（そのデザインは優雅に見える）
👉 つまり「looks + 形容詞」は「be動詞 + 形容詞」と同じ構造で、主語の状態や印象を説明しています。


2️⃣ よく使われる linking verb の例
	• look → ～に見える
		○ The design looks elegant.（そのデザインは優雅に見える）
	• seem → ～のように思える
		○ She seems tired.（彼女は疲れているようだ）
	• appear → ～のように見える
		○ He appears confident.（彼は自信があるように見える）
	• feel → ～に感じる
		○ I feel happy.（私は幸せに感じる）
	• sound → ～に聞こえる
		○ The idea sounds interesting.（そのアイデアは面白そうに聞こえる）
	• taste → ～の味がする
		○ The soup tastes delicious.（そのスープは美味しい味がする）
	• smell → ～の匂いがする
		○ The flowers smell nice.（花は良い匂いがする）
👉 これらは「be動詞と同じように形容詞を後ろに置ける」動詞です。
